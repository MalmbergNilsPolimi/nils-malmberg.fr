La première version, simple et basique, combinait principalement HTML avec un peu de PHP, peu de CSS et pas de JavaScript. L'objectif était de me familiariser avec le développement web.

The nils-malmberg.fr website

Context

During my first year of engineering school, I started developing this personal website out of passion. This project traces its evolution from the very beginning to the current version.

Version 1 – The Basics

The first version combined HTML with some PHP, little CSS and no JavaScript — a learning exercise.

Version 2 – Modernization in Milan

While in Milan, I challenged myself to rebuild the entire site in a weekend. This version introduced FR/EN multilingual support and JavaScript animations.

Version 3 – Responsive Redesign (current)

Optimized for mobile devices using media queries, with a significant code rewrite. Now includes dark/light mode.
